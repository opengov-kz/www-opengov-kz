# QBS Solutions – Government Open Data Portal

Это веб-приложение для демонстрации проектов цифровизации государственного сектора, с особым акцентом на инициативу **"Открытые Данные в Казахстане"**. Сайт разработан с использованием **React + Vite**, реализована мультиязычность (казахский, русский, английский), адаптивная вёрстка и динамическая генерация контента.

## 🚀 Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/opengov-kz/www-opengov-kz.git
cd www-opengov-kz

# Установите зависимости
npm install

# Запустите локальный сервер
npm run dev
```

## 📦 Технологии

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [React Router](https://reactrouter.com/)
- [i18next](https://react.i18next.com/) для мультиязычности
- [CSS Modules](https://github.com/css-modules/css-modules) для стилизации
- [Vercel](https://vercel.com/) для деплоя
